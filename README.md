# food-plate-api

Upload one meal photo and get back every dish on the plate, with calories, protein, carbohydrate, fat and fibre per
dish and for the whole meal. It is an HTTP API that runs on CPU, with both models included.

**Read first:** [Deployment_Guide.pdf](Deployment_Guide.pdf). [DEPLOYMENT.md](DEPLOYMENT.md) has the same content.

```bash
git lfs install                     # once per machine: the model files are stored with Git LFS
git clone https://github.com/dhruv-upmanyu/food-plate-api.git && cd food-plate-api
docker build -t food-plate-api .
docker run -d -p 8000:8000 -e PLATE_API_KEY=<secret> food-plate-api
python api_smoke_test.py --url http://127.0.0.1:8000 --key <secret>
```

If the files in `models/` are only a few hundred bytes after cloning, git-lfs was missing: run
`git lfs install && git lfs pull`.

This repository is generated by `python -m plate.build_deploy` in the project repository. Make changes there, not here.
